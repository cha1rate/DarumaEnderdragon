# だるまさんがころんだエンドラ討伐
## 1.概要
### 1-1.基本ルール
一定時間間隔で訪れる「だるまさんがころんだ」の合図で止まらなければいけない世界でエンドラ討伐を目指します。

### 1-2.システム詳細
大きく3つのフェーズで構成されています。
<li>フェーズ1：エンドラ討伐を進める時間です。</li>
<li>フェーズ2：「だるまさんがころんだ」とコールがかかります。止まる準備をしましょう。</li>
<li>フェーズ3：絶対に動いてはいけません。もし動いてしまうとキルされてしまいます。</li>

### 1-3.各パラメータ
<li>フェーズ1のクールタイムの長さ：4~6分ランダムで決定します。</li>
<li>フェーズ2のコールの長さ：2パターンあり、10%の確率で短いコールが発生します。</li>

## 2.遊び方
### 2-1.想定環境
minecraft java edition 1.21.4

### 2-2.事前準備
まずこのデータパックではゲームの開始時にコマンドを打ち込む必要があるためワールド生成時に必ずコマンドの許可を有効化してください。<br>
その後 saves > 生成したワールドデータ名 > datapacks内にこのデータパックをコピーしてください。<br>
またこのデータパックはリソースパックと一緒に使用することを想定しています。併せてご準備ください。

### 2-3.始め方
下記のコマンドをテキストチャットに打ち込んでください。するとゲームを開始するためのチャットが出てくるので[開始]をクリックしてください。<br>
コマンド：<code>/function daruma_enderdragon:system/guide</code>
その後エンダードラゴンを討伐するまでゲームシステムは常に動き続けます。
